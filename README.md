# 🏃 DidimFit

**모두에게 열린 운동의 시작, 디딤핏**

디딤핏은 사용자의 조건과 체력 상태에 맞는 운동 및 프로그램을 추천하고, 운동 정보를 보다 쉽게 탐색할 수 있도록 돕는 서비스입니다.

---

## 📌 주요 기능

- 로그인 / 회원가입
- 아이디 찾기 / 비밀번호 찾기
- 마이페이지 및 회원정보 수정
- 즐겨찾기
- 사용자 맞춤 운동 추천
- 첫 운동 추천
- 체력 결과 기반 운동 추천
- 운동 프로그램 둘러보기
- 지역 및 종목 기반 프로그램 탐색

## 🚀 Getting Started

### 1. Repository Clone

~~~bash
git clone https://github.com/Public-Data-Contest-Bangi/Public-Data-Contest-FE.git
~~~

### 2. 프로젝트 폴더 이동

~~~bash
cd Public-Data-Contest-FE
~~~

### 3. 패키지 설치

~~~bash
npm install
~~~

### 4. 개발 서버 실행

~~~bash
npm run dev
~~~

---

## 💬 Commit Convention

| Type | Description |
| --- | --- |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `style` | UI 및 스타일 수정 |
| `refactor` | 코드 리팩토링 |
| `chore` | 설정 및 기타 작업 |
| `docs` | 문서 수정 |

### 예시

~~~text
feat: 로그인 및 아이디 찾기 화면 구현
~~~
